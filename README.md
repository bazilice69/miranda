# 🧁 Miranda Confeitaria Artesanal

Aplicativo offline e instalável para a Cristiane controlar encomendas, catálogo, custos, clientes, Páscoa e fluxo de caixa.

## Recursos

- Agenda e status de encomendas, incluindo sinal, pagamento e mensagem pronta para WhatsApp.
- Catálogo com fotos, preços e categorias: doces, bolos e tortas, salgados, pães e pão de queijo, kits de festa e outros.
- **Modo Vitrine**: mostra ao cliente somente fotos, descrição e preço. Custos e margens continuam privados.
- Calculadora de preço por receita: insumos + mão de obra + outros gastos + margem de lucro.
- Financeiro mensal: vendas recebidas, despesas categorizadas e resultado.
- Cadastro de clientes e histórico de pedidos.
- Especial de Páscoa: catálogo reaproveitável de ovos, novidades e resumo da temporada.
- Fotos comprimidas automaticamente para reduzir o espaço ocupado.
- Backup/restauração em arquivo JSON, incluindo fotos, para transferir dados entre celular e PC.

## Dados e sincronização

O app salva os dados no navegador do aparelho. Para usar o mesmo conteúdo no celular e no PC:

1. No aparelho de origem, abra **⚙️ Ajustes → Fazer backup**.
2. Guarde o arquivo JSON no Google Drive, WhatsApp ou e-mail.
3. No outro aparelho, abra **⚙️ Ajustes → Restaurar backup** e selecione esse arquivo.

## Publicação

O projeto é estático e pode ser publicado no GitHub Pages, Netlify ou Cloudflare Pages. Ao abrir por HTTPS, também pode ser instalado como PWA.
